## Назначение

Создание и обработка строк: индексация и срезы, поиск и замена подстрок, разделение и
объединение текста, проверка граничных случаев (пустые строки, пробелы, регистр).

- **Версия Python:** 3.13.14
- **Редактор:** Zed 1.23.2
- **Варианты:** индивидуальные задания 1, 2 и 3 — вариант 17 в каждой группе

## Программы

| Файл | Описание |
|------|----------|
| `replace_spaces.py` | Пример 1: замена пробелов на подчёркивания |
| `remove_middle.py` | Пример 2: удаление средней буквы (или двух) слова |
| `justify_text.py` | Пример 3: равномерное распределение пробелов до заданной длины |
| `individual_01.py` | Задание 1, вариант 17: число вхождений символа в предложение |
| `individual_02.py` | Задание 2, вариант 17: замена «ах» на «ух» |
| `individual_03.py` | Задание 3, вариант 17: перестановка s-й буквы слова на место k-й |
| `doc/report.pdf` | Отчёт |

## Подготовка окружения

Windows:

```
python -m venv .venv
.\.venv\Scripts\python.exe --version
```

Linux/macOS:

```
python3 -m venv .venv
./.venv/bin/python --version
```

Сторонние пакеты не требуются — используется только стандартная библиотека.

## Запуск

Из корня репозитория с активированным окружением; каждое значение вводится отдельной строкой
(без кавычек):

```
python replace_spaces.py
python remove_middle.py
python justify_text.py
python individual_01.py
python individual_02.py
python individual_03.py
```
